# 🎻 Prompt Fiddle

**Prompt Fiddle** — это легковесный CLI-инструмент для локального промпт-инжиниринга (на базе Ollama и OpenAI-совместимых API). Он позволяет работать с промптами как с кодом, настраивать параметры генерации вручную через YAML и видеть цветной `diff` между версиями ответов модели.

## 🚀 Быстрый старт (для пользователей `uv`)

Если у вас установлен [uv](https://github.com), вам даже не нужно клонировать репозиторий для теста! Вы можете запустить инструмент напрямую из GitHub:

```bash
uv run --with pyyaml --with requests --with colorama https://githubusercontent.com
```

### Локальная установка для разработки:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd prompt-fiddle
   ```
2. Запустите проект (uv сам создаст виртуальное окружение и поставит зависимости):
   ```bash
   uv run main.py
   ```

## ⚙️ Настройка

Создайте файлы в корне проекта:

**config.yaml**
```yaml
model: "deepseek-r1:8b" # Ваша локальная модель в Ollama
system_prompt: "Ты — лаконичный технический писатель."
options:
  temperature: 0.0      # Для максимальной воспроизводимости
  seed: 42
```

**input.txt**
```text
Вставьте сюда ваш сырой текст или код для обработки...
```
